### 👨‍💻 About Me

I am a **Full Stack .NET Developer** with 3+ years of engineering experience, specializing in architecting and delivering high-performance business solutions, SaaS platforms, and enterprise web applications.

My core focus centers on building secure, modular backends with **C# and ASP.NET Core (.NET 10)** following **Clean Architecture**, complemented by modern, reactive interfaces with **Angular and TypeScript**, backed by **Microsoft SQL Server**.

- 🚀 **Full Lifecycle Engineering:** Designing normalized database schemas, architecting RESTful APIs, and crafting responsive frontend dashboards.
- 🏛️ **Architecture & Design:** Deep commitment to Clean Architecture, SOLID principles, Repository & Unit of Work patterns, and Dependency Injection.
- 🔐 **Security & Performance:** Experience implementing JWT authentication, refresh-token rotation, Role-Based Access Control (RBAC), multi-tenancy, and SQL query tuning.
